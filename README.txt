PREVIEW
Open index.html in a browser.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a public repository named: tanishqjangid.github.io
3. Upload all files and folders from this project (keep assets/profile.jpg in place).
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Your site will appear at https://tanishqjangid.github.io after GitHub finishes deploying.

BEFORE SHARING
- Add your real GitHub and LinkedIn profile URLs to the navigation/contact area if you want them displayed.
- Add GitHub repository links to the two project cards once the projects are uploaded.
- Check the phone number and email are correct.
- Do not claim skills or project technologies you have not actually used.
